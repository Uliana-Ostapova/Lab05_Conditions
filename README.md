## Пример кода GetHint()
```csharp
string GetHint(int difference)
{
    switch (difference)
    {
        case <= 3:
            return "🔥 Горячо!";
        case <= 10:
            return "🌡 Тепло.";
        case <= 25:
            return "🌀 Прохладно.";
        default:
            return "❄ Холодно!";
    }
}
```

## Ответы на вопросы
**1. Чем `int.TryParse()` безопаснее `int.Parse()`? В каких случаях стоит использовать каждый?**
`int.Parse()` преобразует строку в целое число. Если строка содержит некорректное значение, программа выдаст ошибку.

`int.TryParse()` позволяет проверить ужалось ли преобразовать строку в число. Его удобно использовать, когда пользователь может ввести неправильные данные.

**2. Когда `switch` удобнее, чем цепочка `if/else if`? Приведите пример из реальной жизни.**
`switch` удобнее, когда нужно сравнить одну переменную с несколькими конкретными значениями.
Например, в игре "Угадай число" с помощью `switch` можно выводить подсказку в зависимости от разницы между загаданным числом и введённым числом.

```csharp
if (guess < secret)
{
        int diff = secret - guess;
        string hint = GetHint(diff);
        Console.WriteLine($"↑ Больше {hint}\n");
}
else if (guess > secret)
{
        int diff = guess - secret;
        string hint = GetHint(diff);
        Console.WriteLine($"↓ Меньше {hint}\n");
}
```

**3. Что произойдёт в `switch`, если убрать `break` после одного из `case`?**
Если убрать необходимый блок `break`, программа может выдать ошибку компиляции.

**4. Чем отличается `=` от `==` в C#? Почему это частая ошибка?**
`=` используется для присваивания значений переменной.

`==` используется для сравнения двух значений.

Эти операторы легко перепутать друг с другом из-за схожести, поэтому важно обращать внимание на количество знаков равенства.

**5. Можно ли написать тернарный оператор внутри другого тернарного оператора? Приведите пример из кода лабораторной и оцените читаемость такого кода.**
Да, можно, но делать это не рекомендуется. Тернарный оператор используется для простых случаев «одно из двух».

Если условий больше или код внутри сложный - лучше использовать обычный `if/else`. Читаемость кода важнее краткости.
Пример тернарного оператора:
```csharp
string ageGroup = age >= 18 ? "совершенолетний" : "несовершенолетний";
```
